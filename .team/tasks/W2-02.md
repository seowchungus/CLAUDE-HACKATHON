# W2-02: Coordinator state machine with log and events
Owner: W2 · Timebox: 45 min (target done 12:45) · Depends on: W2-01 · Proposal: §4.3, §4.4, §5.3, §6, §8.4

## Files
- `agents/coordinator.py`: `Coordinator(bundle, run_id, config=None, llm=None)`, `async run()` yielding SSE envelopes exactly per CONTRACTS.md §3 (types, payloads, order, `seq`, `ts`, `log_hash`), and `async approve(...)`. Pure code, no LLM in the coordinator.
  - INIT: write `scenario_loaded` (seq 0) via `core.log.ConsensusLog`, emit `run_started`, `options`.
  - R1 PROPOSE (3 parallel calls) → validate → for each counter: off-grid/duplicate → reject; else `make_option` + `check_option`; infeasible → `counter_checked accepted=false` with failed constraint IDs; feasible → new `opt_cN`, emit `options`. Emit `veto` when an agent ranks first or accepts an infeasible option. A = ∩ acceptable ∩ feasible; tentative = argmin over A of max rank across agents (ties: lower cost_J, then id). Emit `tentative`, `round_ended`.
  - R2 RESPOND: agents see others' structured positions + tentative. All ACCEPT (and tentative feasible) → `consensus` round 2. Else recompute A and tentative (counters allowed).
  - R3 BALLOT: ACCEPT/REJECT only on the tentative; any counter → treated as REJECT with an error. All ACCEPT → `consensus` round 3, else `fallback` NO_CONSENSUS.
  - Empty A at any point after R1 → go straight to the ballot on the best fallback-ranked feasible option; if there are no feasible options at all → `fallback` NO_FEASIBLE (ESCALATE).
  - `timeout`, second schema failure, `rate_limited`, `error`, `killed` → count as REJECT. Kill switch on at start or mid-run → `fallback` LLM_KILLED, using `bundle.fallback` (core.fallback.solve) and no LLM call.
  - **The checker always has the last word:** a consensus option that is not `feasible` is never emitted as `consensus`; it becomes `veto` + fallback.
  - `MAX_ROUNDS` from config, asserted ≤ 3 in code.
  - Then `narration` (skip if narrator not built yet), `awaiting_approval`, `run_ended` (`chain_ok` from `verify_chain`).
  - `approve()` writes an `approved` log entry (actor HUMAN) and returns `{ok, final_hash}`.
- `agents/run_fixture.py`: `python -m agents.run_fixture [--mock|--mock-deadlock|--killed] [--bundle PATH]` prints the event stream as one JSON per line and the log path.
- `agents/tests/test_coordinator.py` (MockLLMClient): consensus path; deadlock → fallback in round 3 with exactly 3 `round_started`; never a `counter_checked` in round 3; killed → fallback with 0 LLM calls; an unsafe all-accept is vetoed; the log verifies.
