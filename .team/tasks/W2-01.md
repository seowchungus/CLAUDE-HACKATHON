# W2-01: Schema, merged prompt template, Gemini client, kill switch
Owner: W2 · Timebox: 45 min (target done 12:00) · Depends on: fixtures only · Proposal: §3, §4.1, §4.2

## Files
- `agents/schema.py`: `Counter`, `AgentPosition`, `AgentMessage` exactly as CONTRACTS.md §2; `build_position_model(option_ids, metric_refs, round)` producing a Pydantic model with per-scenario `Enum`/`Literal` for OptionId and MetricRef (so Gemini's response schema restricts them); `counter` must be null in round `MAX_ROUNDS`. Also `validate_position(raw: dict, ctx) -> (AgentPosition | None, errors: list[str])` for code-side checks (option ids exist, counter value in `counter_allowed_values`, round rules, ranking ⊆ candidates).
- `agents/prompts/agent.md.j2`: the ONE template, blocks in this order with comments marking them: **A** shared protocol (rules, schema summary, turn limits, "every number must come from the metrics table; cite as opt_id.metric; do not calculate; a counter changes ONE parameter to an allowed value"), **B** shared scenario brief (the DOT row, airport, the options table with all metrics, the H1–H7 result per option; identical for all three agents), **C** role charter (ATC / PILOT / GROUND, from proposal §4.1), **D** private domain view (ATC: bank + runway slots + separation; PILOT: fuel, turbulence by FP, connections and pax; GROUND: gates, occupancy, taxiways, ramp shift, next departure), **E** round state (round number and phase, allowed actions, others' last structured positions, tentative option).
  - Blocks A+B must render byte-identical for the three agents (that's the cacheable prefix). Add a test for it.
- `agents/charters.py` (or inside the template): the three charters.
- `agents/client.py`:
  - `LLMClient` protocol: `async def position(self, role, prompt, response_model, round) -> AgentMessage`
  - `GeminiClient` using the `google-genai` SDK async API, `response_mime_type="application/json"`, `response_schema=<model>`, temperature from config, 20 s timeout (`asyncio.wait_for`), 1 retry on schema failure, exponential back-off on HTTP 429 (config.rate_limit), switch to `models.backup` after `max_429_retries`. Returns `AgentMessage` with status, latency, tokens (from usage metadata), retries.
  - `MockLLMClient`: deterministic, no network. Picks rankings from the metrics according to the role's goals (ATC: min bank_delay/max separation; PILOT: min misconnects then fuel; GROUND: min overtime then turnaround). R1: propose, and GROUND counters once with a gate change. R2/R3: ACCEPT if tentative is in its acceptable set. Option `mode="deadlock"` makes PILOT and GROUND reject everything (for the failure-case demo).
  - Reads `GEMINI_API_KEY` (and `_2`, `_3`) from `.env` via python-dotenv. Never log the key.
- `agents/killswitch.py`: `set_llm_enabled(bool)`, `llm_enabled()`. `GeminiClient` returns `status="killed"` immediately when disabled.
- `agents/try_round.py`: `python -m agents.try_round [--mock] [--bundle docs/fixtures/scenario_bundle.json]` renders the three prompts, makes **three separate parallel calls** (`asyncio.gather`) for round 1, and prints each validated `AgentMessage`. `--show-prompt ATC` prints the rendered prompt.
- **Minute-0 check:** list the available models with the SDK and confirm the strings in `config.yaml` exist on the free tier. Write the result (exact model strings, and any per-minute limit you hit) in your DONE line. If a model string is wrong, write BLOCKED with the correct one; MANAGER updates config.yaml.

## Acceptance criteria

2. `python -m agents.try_round` (live, key in `.env`) prints 3 valid positions from 3 separate API calls, each with latency and tokens.
3. `pytest -q agents/tests` passes: A+B prefix identical across roles; unknown option id → error; counter in round 3 → error; off-grid counter value → error.
4. Grep shows no API key in any file outside `.env`.
