# W1-01: Types, config, hash-chained log, data prep
Owner: W1 · Timebox: 35 min (target done 11:55) · Depends on: nothing · Proposal: §2.1, §6, §8.1

## Goal
Lay the foundation everyone imports: frozen types, config loader, the hash-chained log, and the filtered dataset.

## Files
- `.venv` (gitignored): `python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt`
- `core/types.py`: transcribe CONTRACTS.md §1 types **exactly**, plus `LogEntry`, `VerifyResult` (§5) and `MapAirport`, `MapFlight`, `MapPayload` (§4.3)
- `core/config.py`: `load_config(path="config.yaml") -> dict` (cached)
- `core/log.py`: `ConsensusLog` and `verify_chain(path)` per CONTRACTS.md §5. Writes `runs/<run_id>.jsonl`, flushes each line. Seq 0 = `scenario_loaded`.
- `data/prep.py`: Polars lazy scan of `data/raw/flights.csv` → keep `(WEATHER_DELAY > 15 OR LATE_AIRCRAFT_DELAY > 20) AND CANCELLED == 0 AND DIVERTED == 0` → write `data/qualifying.parquet`. Also write:
  - `data/arrivals_index.parquet`: all non-cancelled flights with only the columns needed to build arrival banks, connections and next-tail departures (DATE, AIRLINE, FLIGHT_NUMBER, TAIL_NUMBER, ORIGIN, DEST, SCHEDULED_DEPARTURE, SCHEDULED_ARRIVAL, ARRIVAL_DELAY, DEPARTURE_DELAY). Use a narrower or date-partitioned file if this is too big.
  - `data/status_quo.json`: `{qualifying_flights, weather_delay_min, late_aircraft_delay_min}`, **computed** from the dataset (proposal §1.2, §8.1)
  - **Quirk:** October rows may have numeric airport codes. Drop rows whose ORIGIN/DEST are not 3-letter alphabetic codes (log the count dropped).
- `data/dev_rows.json`: 5 hand-picked dev scenario_ids (mix of weather and late-aircraft, ≥ 3 airports, prefer hubs like ORD/ATL/DFW/DEN). These are excluded from eval.
- `tests/test_log.py`: append 5 entries → `verify_chain` ok; tamper one byte of one line → `ok=False, broken_at=<that seq>`.
- Check that `docs/fixtures/run_log.jsonl` verifies with your `verify_chain` (it was generated with the contract formula). If it doesn't, tell MANAGER (BLOCKED line) rather than changing the formula.

## Acceptance criteria
1. `python -c "from core.types import Scenario, Option, Metrics, CheckReport, FallbackResult, ScenarioBundle, LogEntry, MapPayload"` works.
2. `ScenarioBundle.model_validate(json.load(open('docs/fixtures/scenario_bundle.json'))['bundle'])` succeeds (your types parse the fixture).
3. `python data/prep.py` finishes and prints row counts (raw, qualifying, dropped-numeric-codes), writes the parquet files and `status_quo.json`.
4. `pytest -q tests/test_log.py` passes, and `verify_chain('docs/fixtures/run_log.jsonl').ok is True`.
5. `git status --short` lists no csv/parquet files (gitignored).
