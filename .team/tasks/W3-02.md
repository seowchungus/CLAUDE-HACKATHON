# W3-02: Traffic map, constraint wall, runway/gate Gantt, log viewer
Owner: W3 · Timebox: 45 min (target done 12:45) · Depends on: W3-01 · Proposal: §7.2, §7.4, §7.5, §6

## Files (all in `web/`)
- **Traffic map** (Leaflet, dark free tile layer such as CARTO dark_all; fall back to plain background with airport dots if tiles fail): airports from `map.airports`; great-circle arcs for every `map.flights` entry; disrupted flight highlighted (bright, thick), `bank` arcs converging on the focus airport (thin), `connection` arcs dashed going out. Destination ring. Aircraft markers placed by interpolating along the arc at `map.now_min` (time-zone naive; label "position estimated"). On the `consensus`/`fallback` event, update the disrupted flight's ETA label to the plan's `eta_new_min`. If `run_started.data.chaos_applied` is non-empty, the destination ring turns amber. Static arcs first, then animation if time allows (animation is cut item #3).
- **Constraint wall**: grid options (rows) × H1–H7 (columns), green/red cells with `detail` as tooltip. Rows appear/update on each `options` event (new counter rows flash in). The tentative row is outlined; the final plan row is highlighted; the fallback's choice gets a "B1" tag and `opt_fcfs` a "B0" tag (B0 shown greyed, not a candidate).
- **Runway & gate Gantt** (plain SVG): runway lane with bank arrivals at `est_arr_min` and the disrupted flight at the tentative/plan `runway_slot_min`; gate lanes with `occupied` intervals and the plan's gate window `gate_free_from/to`; conflicts (overlap) glow red. Time axis HH:MM.
- **Log viewer** drawer: fetch `/api/runs/{id}/log`, show entries (seq, ts, actor, event_type, constraint_ids, short hash) and a "chain verified ✓" / "✗ broken at N" badge from `/verify`; a Download button.

## Acceptance criteria
1. In MOCK mode the map shows DFW→ORD highlighted, 10 bank arcs converging on ORD, 5 dashed connections.
2. The constraint wall shows opt_5 failing H3 and opt_6 failing H4; opt_c1 appears after the counter event; consensus row highlighted.
3. The Gantt shows the bank on the runway lane and gate A3 for the plan without conflict.
4. The log drawer shows 29 entries and "chain verified ✓"; Download gives the .jsonl.
5. `npm run build` succeeds.
