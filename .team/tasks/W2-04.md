## Files
- `agents/budget.py` (CONTRACTS v1.2 §4.4): ledger `runs/llm_budget.json` = `{date_pacific: "YYYY-MM-DD", keys: {GEMINI_API_KEY: n, ...}}`, file-locked (`fcntl.flock`) so the server, eval and CLIs share one count. Day boundary = midnight `America/Los_Angeles` (`zoneinfo`). On a new ledger, start each key at `llm_budget.used_before_ledger[key]` (211 for the main key today). `reserve(key)` atomically increments and returns False once `used >= per_key_daily_cap` (480). Also a process-wide RPM limiter (`per_key_rpm_cap` = 12/min sliding window) that **waits**, not errors. `budget_status()` → `LLMBudget`. Never store or print the key itself, only its env-var name.
- `agents/client.py`:
  - Call `reserve()` before **every** real request, including schema retries. Refused → `AgentMessage(status="rate_limited", errors=["daily LLM budget exhausted"])`, which counts as REJECT, so the run falls back safely.
  - `models.backup: null` → no model cascade at all. On 429/503: back off once (`max_429_retries: 1`), then `rate_limited`.
  - Models from config: all `gemini-3.5-flash-lite`. **Verify the exact string** with `client.models.list()` (a list call, not a generation call; it shouldn't count against RPD, but do it once only) and report it. If it differs, write BLOCKED with the right string; MANAGER updates config.
  - Narrator: `models.narrator_llm: false` → deterministic template, 0 calls.
  - Log one line per real request: `LLM_CALL key=GEMINI_API_KEY model=... used=223/480`.
- `agents/budget_cli.py`: `python -m agents.budget_cli` prints the status; `--set GEMINI_API_KEY=<n>` corrects the ledger to the dashboard reading (MANAGER/human use only).
- Charters / block D (workbook rules, wording only, no numbers computed by the LLM): PILOT knows final reserve 30 min, assumed spare 45 min of holding, max crew duty 13 h; GROUND knows the 20-min gate-change notice, 8-h shifts with overtime at 1.5×, the spare-gate count; ATC knows the arrival capacity and wake rules come from the workbook. Every number they cite still comes from the metrics table (`opt_id.metric`).
- Coordinator: if the remaining budget is below 9 calls at run start, skip the LLM and go straight to `fallback` with reason `LLM_ERROR` and a clear message "LLM budget exhausted" (don't start a negotiation you can't finish).

## Acceptance criteria
1. `pytest -q agents/tests` passes, incl.: two processes (or threads) reserving concurrently never exceed the cap; cap reached → `rate_limited` and the run ends in a feasible fallback; schema retry consumes budget; Pacific-midnight rollover resets the count; RPM limiter waits.
2. `python -m agents.budget_cli` shows `GEMINI_API_KEY used 211/480` on a fresh ledger.
3. `grep -rn "backup" agents/` shows no remaining model cascade.
4. DONE line: the verified Flash-Lite model string and the expected calls per run (min/typical/max).
